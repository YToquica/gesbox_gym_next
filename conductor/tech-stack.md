# Technology Stack: GesBox

## Core Framework & Runtime
- **Framework:** Next.js 16 (App Router, Server Actions)
- **UI Library:** React 19
- **Language:** TypeScript 5
- **Package Manager:** npm / pnpm

## UI & Styling
- **Styling:** Tailwind CSS v4
- **Components & Primitives:** Radix UI, Shadcn UI patterns
- **Icons:** Lucide React
- **Animation & Utilities:** clsx, tailwind-merge, class-variance-authority, tw-animate-css

## Forms & Validation
- **Form Management:** React Hook Form
- **Schema Validation:** Zod
- **Resolver:** @hookform/resolvers

## Backend & Persistence
- **Database & Auth:** Supabase (PostgreSQL, Supabase Auth)
- **Client/Server SDKs:** @supabase/supabase-js, @supabase/ssr

## State Management & API
- **Server State:** TanStack React Query v5
- **Payments Integration:** Mercado Pago SDK

## Quality & Testing
- **Unit & Integration Testing:** Jest, @testing-library/react, @testing-library/jest-dom
- **End-to-End (E2E) Testing:** Playwright
- **Linting:** ESLint (eslint-config-next)
